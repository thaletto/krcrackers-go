## AWS Lambda

### Build

```bash
make build-lambda    # GOOS=linux GOARCH=arm64 → bootstrap + lambda.zip
make deploy-lambda   # Updates Lambda function
```

### Deploy

```bash
make build-lambda    # GOOS=linux GOARCH=arm64 → bootstrap + lambda.zip
make deploy-lambda   # updates Lambda code + pushes .env.production via deploy-env
```

There is no SAM template: deploys go through the AWS CLI. `deploy-env` reads `.env.production` and pushes its variables to the function's configuration.

### Environment Variables

Set via `deploy-env` (reads `.env.production`) or the Lambda console:

```
JWT_SECRET=<your-secret>
APP_ENV=production
CLOUDFLARE_API_TOKEN=<token>
CLOUDFLARE_ACCOUNT_ID=<account-id>
CLOUDFLARE_DATABASE_ID=<d1-id>
```

## Performance

| Metric | Value |
|--------|-------|
| Cold start | ~200ms (arm64) |
| Warm invocation | ~5ms |
| Binary size | ~15MB (compressed) |
| Memory | 128MB (configurable) |

## Database

### Development (SQLite)

```bash
make dev-db    # Export prod D1 → .data/dev.sqlite
```

### Production (Cloudflare D1)

Migrations run via CLI:

```bash
make migrate-up
```

## Health Check

```bash
curl http://localhost:8080/health
# {"status": 200, "message": "ok"}
```

## Integration Tests

```bash
make test-endpoints    # 64 endpoint tests
```

Starts server, runs tests, cleans up.
