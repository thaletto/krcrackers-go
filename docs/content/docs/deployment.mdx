## AWS Lambda

### Build

```bash
make build-lambda    # GOOS=linux GOARCH=arm64 → bootstrap + lambda.zip
make deploy-lambda   # Updates Lambda function
```

### SAM Template

```yaml
AWSTemplateFormatVersion: '2010-09-09'
Transform: AWS::Serverless-2016-10-31

Globals:
  Function:
    Timeout: 30
    MemorySize: 128
    Runtime: provided.al2023
    Architectures:
      - arm64

Resources:
  ApiFunction:
    Type: AWS::Serverless::Function
    Properties:
      Handler: bootstrap
      Events:
        CatchAll:
          Type: Api
          Properties:
            Path: /{proxy+}
            Method: ANY
```

### Environment Variables

Set via Lambda console or SAM:

```
JWT_SECRET=<your-secret>
APP_ENV=production
CLOUDFLARE_API_TOKEN=<token>
CLOUDFLARE_ACCOUNT_ID=<account-id>
CLOUDFLARE_DATABASE_ID=<d1-id>
```

## Performance

| Metric | Value |
|--------|-------|
| Cold start | ~200ms (arm64) |
| Warm invocation | ~5ms |
| Binary size | ~15MB (compressed) |
| Memory | 128MB (configurable) |

## Database

### Development (SQLite)

```bash
make dev-db    # Export prod D1 → .data/dev.sqlite
```

### Production (Cloudflare D1)

Migrations run via CLI:

```bash
make migrate-up
```

## Health Check

```bash
curl http://localhost:8080/health
# {"status": 200, "message": "ok"}
```

## Integration Tests

```bash
make test-endpoints    # 64 endpoint tests
```

Starts server, runs tests, cleans up.
