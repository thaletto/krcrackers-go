## Prerequisites

- Go 1.26+
- SQLite (installed automatically via `modernc.org/sqlite`)
- `wrangler` CLI (for Cloudflare D1 access)

## Quick Start

```bash
# Export production D1 database to local SQLite
make dev-db

# Start dev server on :8080
make run
```

## Environment Variables

Copy `.env.example` to `.env` and configure:

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `JWT_SECRET` | Yes |  | HMAC-SHA256 signing key (panics if empty) |
| `APP_ENV` | No | `development` | `development` (SQLite) or `production` (D1). Unset + `CLOUDFLARE_API_TOKEN` present implies `production` |
| `LOCAL_DB_PATH` | No | `.data/dev.sqlite` | SQLite file path |
| `CLOUDFLARE_API_TOKEN` | Prod |  | Cloudflare API token |
| `CLOUDFLARE_ACCOUNT_ID` | Prod |  | Cloudflare account ID |
| `CLOUDFLARE_DATABASE_ID` | Prod |  | D1 database ID |
| `R2_ACCOUNT_ID` | No |  | Cloudflare R2 account ID |
| `R2_ACCESS_KEY_ID` | No |  | R2 access key |
| `R2_SECRET_ACCESS_KEY` | No |  | R2 secret key |
| `R2_BUCKET_NAME` | No |  | R2 bucket name |
| `R2_PUBLIC_URL_BASE` | No |  | Public base URL for uploaded files |
| `GOOGLE_OAUTH_CLIENT_ID` | No |  | Google OAuth web client ID (enables Google login) |
| `WHATSAPP_API_TOKEN` | No |  | WhatsApp Cloud API access token |
| `WHATSAPP_PHONE_NUMBER_ID` | No |  | WhatsApp Business phone number ID |
| `WHATSAPP_FROM_NUMBER` | No |  | WhatsApp sender number |
| `PORT` | No | `8080` | HTTP server port |

## Make Targets

| Target | Description |
|--------|-------------|
| `make dev-db` | Export prod D1 → local SQLite |
| `make run` | Start dev server |
| `make dev` | `dev-db` + `run` |
| `make stop` | Kill running server (frees :8080) |
| `make watch` | Hot reload (requires `air`) |
| `make build` | Compile all packages |
| `make test` | Run tests |
| `make test-endpoints` | 64-endpoint integration test |
| `make migrate-up` | Apply pending migrations |
| `make migrate-down` | Rollback latest migration |
| `make migrate-status` | Show migration status |
| `make docs` | Build and serve docs |
| `make docs-update` | Regenerate OpenAPI spec + build docs |

## Dual Entry Points

### Standalone HTTP Server

```bash
make run    # or: go run ./src
```

### AWS Lambda

```bash
make build-lambda    # builds to bootstrap + lambda.zip
make deploy-lambda   # updates Lambda function
```

Both entry points share the identical `newHandler()` wiring logic.

## Hot Reload

Requires `air`:

```bash
go install github.com/air-verse/air@latest
make watch
```

## Environment Files

`.env` (shared defaults) → `.env.local` (personal, gitignored). Loaded by `godotenv` at startup.

## Tests

All `_test.go` files live under `tests/...`, mirroring the package layout (e.g. tests for `src/services/auth/` go in `tests/services/auth/`). Nothing under `src/` has test files, so the blackbox boundary stays intact.

```bash
make test             # go test ./... (unit + blackbox tests)
make test-endpoints   # starts server, runs 64 endpoint tests, cleans up
```
