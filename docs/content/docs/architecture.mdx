## Layer Responsibilities

| Layer | Owns | Must Not Own |
|-------|------|--------------|
| `server` | JSON helpers, request logging | Business logic, data access |
| Auth middleware | JWT validation, user injection | Business logic |
| Service handlers | HTTP decode/validate/respond, routing | SQL, transactions |
| Repositories | SQL, row mapping, transactions | HTTP, validation |
| `database` | `DB`/`Tx`/`Row` interfaces | SQL queries |
| `eventbus` | Pub/sub, handler registration | Business logic |
| `config` | Env loading, config structs | Business logic |

## Service Pattern

**Repository**  owns SQL, row mapping, transactions:

```go
type Repository interface {
    Create(ctx context.Context, input ProductInput) (Product, error)
    List(ctx context.Context, limit, offset int) (ListProductsResponse, error)
    Get(ctx context.Context, id int) (Product, error)
    Update(ctx context.Context, id int, input ProductInput) (Product, error)
    Delete(ctx context.Context, id int) error
}
```

**Service (handlers)**  thin HTTP adapters, delegate to repository:

```go
type Service struct {
    repo Repository
    bus  eventbus.Bus
}

func (s *Service) RegisterRoutes(mux *http.ServeMux) {
    mux.HandleFunc("POST /path", s.handler)
}
```

### Token Strategy

- **Access token**: HMAC-SHA256 JWT, 15-minute expiry, HttpOnly cookie
- **Refresh token**: 64-char hex, 7-day expiry, stored in DB + HttpOnly cookie
- No tokens in response body  all cookie-based

| Middleware | Purpose |
|-----------|---------|
| `WithAuth` | Validates JWT from cookie/header, injects user into context |
| `WithAdmin` | Requires `role=admin` after `WithAuth` |
| `WithOptionalAuth` | Attaches user if present, proceeds unauthenticated if not |

## Known Risks

- **D1 transactions not atomic**: `d1Tx.Commit()` executes sequentially; crash mid-commit leaves partial state
- **No test files**: Zero `_test.go` files; regressions undetected
