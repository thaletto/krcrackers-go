On-demand PDF invoice generation with sequential invoice numbers (INV-0001, INV-0002, ...). Invoice numbers are stored on the order record after first generation.

## Endpoints

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| `GET` | `/invoices/{id}` | WithAuth | Download PDF invoice |
| `GET` | `/admin/invoices/{id}` | Admin | Download PDF invoice (admin) |

## Response

Returns a PDF file with `Content-Type: application/pdf` and `Content-Disposition: attachment; filename=invoice-{id}.pdf`.

## PDF Contents

- Company header (KR Crackers)
- Invoice number and date
- Customer details (name, email, phone, address)
- Line items table (product, qty, unit price, total)
- Order total

## Invoice Number Format

```
INV-0001
INV-0002
INV-0003
...
```

Sequential counter stored in `invoice_counters` table. Generated once per order and stored on the `orders.invoice_number` column.
