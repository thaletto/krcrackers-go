Customer profile and shipping address management. All routes require authentication.

## Endpoints

### Profile

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| `GET` | `/customers/profile` | WithAuth | Get profile |
| `PUT` | `/customers/profile` | WithAuth | Update profile |

### Addresses

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| `GET` | `/customers/addresses` | WithAuth | List addresses |
| `POST` | `/customers/addresses` | WithAuth | Create address |
| `PUT` | `/customers/addresses/{id}` | WithAuth | Update address |
| `DELETE` | `/customers/addresses/{id}` | WithAuth | Delete address |
| `PUT` | `/customers/addresses/{id}/default` | WithAuth | Set default address |

## Address Body

```json
{
  "label": "Home",
  "street": "123 Main St",
  "city": "Mumbai",
  "state": "Maharashtra",
  "pincode": "400001",
  "country": "India",
  "isDefault": true
}
```

## Notes

- Setting an address as default unsets the previous default
- Country defaults to "India" if omitted
- Label defaults to "Home" if omitted
- Required fields: `street`, `city`, `state`, `pincode`
