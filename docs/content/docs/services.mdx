## Auth

Handles user registration, login, Google OAuth, JWT management.

| Endpoint | Method | Auth | Description |
|----------|--------|------|-------------|
| `/auth/register` | POST | Public | Register with email+password |
| `/auth/login` | POST | Public | Login with email+password |
| `/auth/google` | POST | Public | Login with Google ID token |
| `/auth/refresh` | POST | Public (cookie) | Rotate refresh token |
| `/auth/logout` | POST | Public | Revoke token, clear cookies |
| `/auth/me` | GET | WithAuth | Current user profile |

## Customers

Profile and address CRUD with "set default" logic.

| Endpoint | Method | Auth | Description |
|----------|--------|------|-------------|
| `/customers/profile` | GET | WithAuth | Get profile |
| `/customers/profile` | PUT | WithAuth | Update profile |
| `/customers/addresses` | GET | WithAuth | List addresses |
| `/customers/addresses` | POST | WithAuth | Create address |
| `/customers/addresses/{id}` | PUT | WithAuth | Update address |
| `/customers/addresses/{id}` | DELETE | WithAuth | Delete address |
| `/customers/addresses/{id}/default` | PUT | WithAuth | Set as default |

## Products

Catalog with search, filtering, sorting. Publishes events to event bus.

| Endpoint | Method | Auth | Description |
|----------|--------|------|-------------|
| `/products` | GET | Public | List/search (q, category, brand, price range, sort) |
| `/products/{id}` | GET | Public | Get single product |
| `/admin/products` | POST | Admin | Create product |
| `/admin/products/{id}` | PUT | Admin | Update product |
| `/admin/products/{id}` | DELETE | Admin | Delete product |

### Query Parameters

| Param | Type | Description |
|-------|------|-------------|
| `q` | string | Full-text search |
| `category` | string | Filter by category |
| `brand` | string | Filter by brand |
| `min_price` | float | Minimum price |
| `max_price` | float | Maximum price |
| `sort` | string | `price_asc`, `price_desc`, `name_asc`, `name_desc` |
| `limit` | int | Max results (0 = all) |
| `offset` | int | Pagination offset |

## Orders

Full order lifecycle: checkout → status updates → events.

| Endpoint | Method | Auth | Description |
|----------|--------|------|-------------|
| `/orders/checkout` | POST | WithAuth | Place order (multipart: address, items, screenshot) |
| `/orders/my` | GET | WithAuth | List my orders |
| `/orders/my/{id}` | GET | WithAuth | Get my order |
| `/orders/my/{id}` | DELETE | WithAuth | Cancel pending order |
| `/admin/orders` | GET | Admin | List all orders |
| `/admin/orders/{id}` | GET | Admin | Get order details |
| `/admin/orders/{id}/status` | PATCH | Admin | Update status (triggers events) |
| `/admin/dashboard` | GET | Admin | Stats: total, pending, revenue, new customers |

## Invoices

PDF generation with sequential numbering.

| Endpoint | Method | Auth | Description |
|----------|--------|------|-------------|
| `/invoices/{id}` | GET | WithAuth | Download PDF invoice |
| `/admin/invoices/{id}` | GET | Admin | Download PDF invoice |

Invoice numbers: `INV-0001`, `INV-0002`, etc. Stored in `invoice_counters` table and assigned on first generation.
