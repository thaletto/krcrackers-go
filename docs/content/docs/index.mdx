Go-powered e-commerce backend with order lifecycle management, product catalog, search, and admin dashboard. Built with clean layered architecture and event-driven pub/sub.

## Features

- **Order Lifecycle**  Pending → Confirmed → Shipped → Delivered / Cancelled
- **Product Catalog**  CRUD with search, filtering, sorting via Meilisearch
- **Auth**  Google OAuth + email/password, JWT + refresh tokens in HttpOnly cookies
- **Event-Driven**  In-memory pub/sub for cross-service communication
- **Admin Dashboard**  Order management, stats, product CRUD
- **PDF Invoices**  On-demand generation with sequential numbering
- **WhatsApp Notifications**  Order status updates via Cloud API
- **Dual Deployment**  Standalone HTTP server or AWS Lambda

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Language | Go 1.22+ |
| Database | SQLite (dev) / Cloudflare D1 (prod) |
| Search | Meilisearch |
| Storage | Cloudflare R2 (S3-compatible) |
| Notifications | WhatsApp Cloud API |
| Auth | JWT (HS256) + Google JWKS |
| PDF | gofpdf |
| Deploy | HTTP server / AWS Lambda |

## Quick Start

```bash
make dev-db    # Export prod D1 → local SQLite
make run       # Start dev server on :8080
```

## API Overview

| Service | Base Path | Auth |
|---------|-----------|------|
| Auth | `/auth/*` | Public |
| Customers | `/customers/*` | WithAuth |
| Products | `/products/*` (reads), `/admin/products` (writes) | Public reads, admin writes |
| Orders | `/orders/*`, `/orders/checkout` | Mixed |
| Admin | `/admin/*` | WithAuth + WithAdmin |
| Invoices | `/invoices/{id}` | WithAuth |
