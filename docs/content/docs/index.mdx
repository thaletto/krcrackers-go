KR Crackers is a customer-facing e-commerce backend for a fireworks/crackers business. It handles product catalog, order lifecycle, payment proof uploads, PDF invoices, and WhatsApp notifications.

## Tech Stack

- **Language**: Go 1.26.3
- **Database**: Cloudflare D1 (prod) / SQLite (dev)
- **Search**: Meilisearch
- **Storage**: Cloudflare R2 (S3-compatible)
- **Notifications**: WhatsApp Cloud API
- **Auth**: JWT + Google JWKS
- **Deploy**: AWS Lambda (arm64)

## Quick Start

```bash
# Clone and setup
cp .env.example .env.local
# Edit .env.local with your credentials

# Start development
make dev        # export prod DB + start server
make run        # just start server
make stop       # kill running server
```
